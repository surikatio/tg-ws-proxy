# Android-приложение

Прокси работает прямо на телефоне: приложение поднимает MTProto-прокси на `127.0.0.1:1443`, а Telegram на том же устройстве подключается к нему. Ничего в локальной сети и никакого сервера не требуется — телефон самодостаточен, в том числе на мобильном интернете.

## Как это устроено

```
Telegram (телефон) → 127.0.0.1:1443 → приложение → WebSocket → Telegram DC
```

Приложение не переписывает протокол: внутри него работает тот же Python-пакет `proxy/`, что и на десктопе, — через [Chaquopy](https://chaquo.com/chaquopy/). Поэтому исправления в мосте, фолбэках и пуле соединений автоматически действуют и на телефоне.

Слои:

| Файл | Роль |
|---|---|
| `android/app/src/main/python/proxy_bridge.py` | Обёртка над ядром: `start` / `stop` / `status`, свой event loop |
| `ProxyService.kt` | Foreground-сервис, держит прокси живым и показывает уведомление |
| `MainActivity.kt` | Экран: запуск/остановка, «Подключить в Telegram», копирование секрета |
| `Prefs.kt` | Порт и постоянный секрет |

Ядро `proxy/` копируется в сборку Gradle-таском `syncProxyCore` — второй копии кода в репозитории нет.

## Сборка

Нужны Android Studio (или Android SDK) и интернет: Gradle скачает Chaquopy и рантайм Python.

```bash
cd android
./gradlew assembleDebug          # Windows: gradlew.bat assembleDebug
```

APK окажется в `android/app/build/outputs/apk/debug/`.

Проще открыть папку `android/` в Android Studio и нажать Run — она сама подтянет Gradle нужной версии.

Установка на подключённый телефон:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Использование

1. Запустите приложение и нажмите **«Запустить»** — появится постоянное уведомление.
2. Нажмите **«Подключить в Telegram»**. Откроется окно подключения к прокси с уже заполненными адресом, портом и секретом — останется нажать «Подключиться».
3. Если Telegram не открылся, добавьте прокси вручную: тип **MTProto**, сервер `127.0.0.1`, порт `1443`, секрет — из приложения (кнопка «Скопировать секрет»).

Секрет сохраняется между запусками, поэтому настраивать Telegram нужно один раз.

## Что важно знать

- **Прокси живёт, пока висит уведомление.** Это foreground-сервис: без него Android заморозит процесс через несколько минут, и Telegram молча потеряет связь. Уведомление убрать нельзя — таково требование системы.
- **Отключите оптимизацию батареи** для приложения (Настройки → Приложения → TG WS Proxy → Батарея → «Без ограничений»), иначе агрессивные прошивки (Xiaomi, Huawei, Samsung) всё равно усыпят сервис.
- **Расход батареи выше**, чем у обычного Telegram: трафик проходит через дополнительный слой, а Python на телефоне не бесплатен. Для постоянного использования сервер в локальной сети или ZeroTier экономнее.
- **Размер APK ~40 МБ** — внутри рантайм Python и `cryptography` для двух ABI (`arm64-v8a`, `x86_64`).
- Прокси слушает только `127.0.0.1`, то есть доступен исключительно приложениям этого же телефона. Раздать его другим устройствам нельзя — для этого есть [режим локальной сети](./LanServer.md).

## Состояние

Python-мост протестирован на десктопе: запуск, приём подключений, статистика и корректная остановка с освобождением порта работают. Kotlin-часть и сборка APK **не проверялись на устройстве** — нужен прогон в Android Studio. Ожидаемые места для правок при первой сборке: версии плагинов в `build.gradle.kts` и наличие колеса `cryptography` для выбранной версии Python в репозитории Chaquopy (если его нет, `proxy/_aes.py` умеет работать и без него — но тогда потребуется бэкенд через `javax.crypto`).
